# Paradise Nursery – Shopping Application

A responsive houseplant shopping application built with React, React Router, Redux Toolkit and React-Redux.

## Features
- Landing page with Paradise Nursery branding and a Get Started call to action.
- About Us page describing the nursery.
- 18 houseplants across three categories: Air Purifying, Low Maintenance and Decorative Foliage.
- Product cards with plant thumbnails, names, prices and Add to Cart controls.
- Redux-powered cart with add, remove and quantity-update reducers.
- Cart item quantities, per-item totals, order total and item count.
- Checkout placeholder ("Coming Soon") and continue-shopping navigation.
- Responsive layout for desktop and mobile screens.

## Run locally
1. Install Node.js (18 or later).
2. Clone this repository.
3. In the project directory, run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Main assessment files
- `App.jsx` – application routes and landing page.
- `App.css` – styling, including the landing-page background image.
- `AboutUs.jsx` – About Us page.
- `CartSlice.jsx` – Redux cart slice and reducers.
- `ProductList.jsx` – plant categories and product cards.
- `CartItem.jsx` – shopping cart and order summary.

## Technology
React · Redux Toolkit · React-Redux · React Router · Vite
